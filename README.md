🎮 Jogo da Velha em C#

Este projeto consiste no desenvolvimento de um Jogo da Velha em linguagem C#, executado via console. O objetivo foi aplicar conceitos fundamentais de programação, organização de código e lógica de jogos.

📌 Funcionalidades

✔️ Modo Jogador vs Jogador

✔️ Modo Jogador vs Computador

✔️ Sistema de dificuldade contra o computador

✔️ Ranking com contagem de vitórias e empates

✔️ Interface interativa via console

✔️ Reinício automático das partidas

🛠️ Tecnologias Utilizadas

C#

.NET

Programação Orientada a Objetos (POO)

Estruturas de decisão e repetição

Manipulação de arrays

🎯 Objetivo do Projeto

Este projeto foi desenvolvido com foco em aprendizado e prática dos fundamentos da programação, incluindo lógica, organização estrutural e interação com o usuário.

▶️ Como Executar

Clone o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git


Abra o projeto em uma IDE compatível com C# (Visual Studio, VS Code, etc.)

Execute o arquivo principal do projeto.
